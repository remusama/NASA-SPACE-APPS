# NASA-SPACE-APPS: Space Station 5 VR Experience

An immersive Virtual Reality (OpenXR / SteamVR) exploration experience of **Space Station 5** and deep cosmic environment built in **Unity 6 (Universal Render Pipeline)**.

## 🚀 Features
- **Space Station 5 Architecture**: Full 1,000m diameter orbital station with walkable ring corridors, command rotunda, observation decks, residential sector, science labs, engineering, and orbital shuttle docking bays.
- **VR & Desktop Hybrid Controls**: Native OpenXR `TrackedPoseDriver` support for 6DOF headset tracking (SteamVR, Meta Quest Link, HTC Vive, Index) and standard Desktop first-person navigation.
- **Cosmic Environment**:
  - Photorealistic 3D Earth with dynamic surface, atmospheric rim lighting, and cloud layers.
  - Proportional 3D Moon system with topographical crater mapping.
  - Radiant Sun with corona flare and solar lighting.
  - Supermassive Black Hole with Keplerian accretion disk and relativistic vortex.
  - Deep space 4K starfield.

## 🛠️ Requirements & Setup
- **Engine**: Unity 6 (6000.x) with Universal Render Pipeline (URP).
- **VR Support**: OpenXR (`com.unity.xr.openxr`) and XR Management (`com.unity.xr.management`).
- **Main Scene**: `Assets/SpaceStation5/Scenes/SpaceStation5.unity`
